使用既有授权账号、独立验证目录和 9.418 秒合成语音，在完整 x64 原生应用实际点击上传与转写。未操作用户已有录音内容。

## 结果与修复

- 首次真实上传、转写完成，但需手动刷新才出现云端副本入口。现在处理完成通知按 ID 拉取该录音、合并列表并保留本机选择；退出账号、旧凭据、已删除关联的延迟响应不回填。
- 首次默认窗口中逐字稿被版本区和播放器挤出视口。现在版本操作独立标签，音频播放区可折叠，详情可滚动，标题单行省略；保留有限高度以维持列表虚拟化。修复后默认窗口实际显示三段转写，底部操作需滚动。
- 第二次真实上传无需手动刷新即出现云端内容入口。最大化窗口实际问答返回“The team will review the design tomorrow.”，引用第二段；双击引用后加载云音频，定位到 00:00:03 并选中对应段落。
- 发现测试目录未隔离云内容缓存与说话人存储；改为 App 注入相同应用目录。最终发布版本重启读取测试录音成功，缓存实际写入 fixture/CloudContent。
