# WinUI 3 第一版视觉评审

后续状态：用户已授权继续真实原生实现，旧的“等待评审”暂停条件已解除。本文保留设计阶段的材料属性与对照规则；当前实施进度以 [界面重设计](windows-winui-visual-redesign.md) 和 [原生验证](windows-winui-validation.md) 为准。

2026-09-16。当前交付为设计稿和交互示意，未改生产界面、未连接真实音频或云服务，不能作为 WinUI 实机验收。示例录音、字幕和回答均为虚构内容。完整迁移任务仍保留在原 RFC。

## 设计方向

轻巧的悬浮工具，安静的回顾空间。统一采用 Windows 原生控件可实现的尺寸、字体和交互方式；蓝色主要用于选中、定位、开始/停止和播放，不给每块内容加装饰卡片。录音库保留列表与详情；字幕以文字为主；录音条只突出当下操作。

交互视觉稿为当前任务中的 `recappi-winui-direction.html`。可切换三种窗口、明暗外观、录音空闲/进行中、字幕短句/长句/历史/连接恢复。支持示例列表切换、搜索、摘要/逐字稿/问答、引用定位、播放状态、麦克风和字幕显隐。上传、导出等仅展示入口；不产生真实副作用。

## 设计规则与状态

- 窗口圆角默认 12 px；常规控件 6 px；详情边距 24 px；侧栏默认 232 px。预览提供圆角和详情留白的调整选项。
- 常规按钮高度 34 px，图标 16 px，图文间距 8 px；字幕工具按钮 28 px、内边距 5 px。图标占位统一，不靠空格和逐控件偏移调位置。
- 字体以 Segoe UI Variable / Segoe UI 为基础；内容标题 23 px、正文 14 px、字幕原文 17 px、译文 15 px、辅助信息 11–12 px；计时和时间戳使用等宽数字。
- 常规窗口采用 Mica 方向的背景与不透明阅读面；字幕和录音条采用不透明底色及系统阴影，优先确保背景复杂时可读。当前预览用纯色近似，不证明实际材质已实现。
- 字幕状态切换提供 180 ms 轻微位移示意，并尊重减少动态效果。真实字幕更新应保持阅读位置、不随电平刷新整窗，具体原生动画和性能待实现阶段验证。
- 录音条当前稿覆盖空闲和录音；后续必须补齐 starting、停止保存、完成、错误、丢弃确认及自动停止提醒。
- 字幕当前稿覆盖双语短句、长句、三句历史、连接恢复、原译文显隐；实际长历史应虚拟化/有界渲染并保留滚动控制。
- 录音库当前稿覆盖已处理、本机仅字幕、云端录音、搜索无结果、摘要/逐字稿/示例问答。加载、分页、导入进度、权限或服务失败仍列入后续实现清单。

## 设计稿检查

证据目录：`build/native-desktop-validation/winui-redesign-review-01`；`review-checks.json` 记录浏览器预览检查。检查过 1024 / 736 / 480 / 320 px 视口下三种窗口的可见内容横向边界；指定操作控件的图标与控件垂直中心差为 0。此测量仅证明布局框居中，字形的光学对齐仍需实际截图和原生控件复查。

已检查示例引用跳转、问答反馈、列表切换、本机未处理状态、搜索及键盘清空、录音开始/停止、麦克风切换、字幕历史/显隐与至少保留一种显示。问答发送最初没有预览反馈，已修复按钮和回车路径。检查未产生真实云请求。

预览服务器曾残留旧子进程；清理并核对唯一监听与最新内容后，重新检查了修订版。浏览器裁剪/整页截图在本机缩放下存在比例异常，交付截图采用普通视口捕获，不据裁剪图测量像素。没有把原生 UIA 崩溃判为解决。
