## ADR：采用 WPF + C# 原生核心

2026-09-15。用户要求功能对齐且尽量轻量，不要求 macOS 外观。WinUI 3 和 WPF 均完成最小三窗口程序构建与自包含发布。选用 WPF：无需随应用额外带 Windows App SDK，已有 .NET/WASAPI 代码可直接共享；当前产品不依赖 WinUI 专有控件。不是基于初期探针错误淘汰 WinUI。

Windows 11 build 26200，x64，32 逻辑处理器；Release/self-contained，普通控件三窗口。每种状态先等待 2 秒，采样 3 秒；单次粗略基线，不是统计意义上的性能承诺。
